项目介绍

这个站点不是只完成页面展示，而是把用户登录、数据隔离、图片上传、接口联调和部署流程串成了一个完整闭环。面试时我可以从任意模块开始，讲清楚它的状态管理、接口设计和线上运行方式。

  • Netlify 托管前端静态资源
  • Render 运行 Express API 服务
  • Supabase 保存用户、日记和私有图片路径
